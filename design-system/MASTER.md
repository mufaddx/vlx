# VIDLIX Design System

Premium privacy-focused social technology platform. Web-only. App-like on mobile.

## Product

- Type: Social + video + live + optional dating
- Tone: Trust, privacy, modern, not dating-app cliché, not Omegle clone
- Pattern: Hero-centric + feature-rich showcase + deep CTAs

## Style

- Glassmorphism on dark ink surfaces, restrained motion (150–300ms)
- Soft depth, high contrast text, no neon cyberpunk, no emoji-as-icons
- Light / Dark / System

Accent is teal (connection/privacy), secondary violet (live/social). Avoid Tinder pink as brand.

## Typography

- Headings: Space Grotesk
- Body: DM Sans
- Minimum 16px body on mobile
- Line height 1.5–1.7

## Motion

- Transform/opacity only
- Respect `prefers-reduced-motion`
- Touch targets ≥ 44px

## Anti-patterns

- No Omegle-style stranger chat chrome
- No Tinder card clone
- No random stock photography wallpaper
- No copyrighted third-party brand assets
- No emoji icons
